# 开发与验收

## 从源码构建

需要 Git、Node.js 24、npm、Python 3，以及能够访问 GitHub 和 npm 的网络。在仓库根目录运行：

```sh
python3 rebuild.py --out ./rebuilt-package
```

脚本检出固定的上游提交、应用 [源码补丁](../llama-ui-zh-b12375.patch)、运行检查与生产构建，再生成可安装的目录。它不会修改已安装的应用或启用补丁。

构建资源会对齐该引擎内嵌的脚本文件名，保证启用 API 密钥时页面脚本也能加载；同时更新 Service Worker 的资源版本，避免沿用旧英文脚本缓存。

直接下载仓库源码不包含 `dist/`。运行构建脚本后，使用输出目录中的安装与恢复脚本。

## 已完成的验收

- Svelte/TypeScript 检查：0 错误、0 警告；生产构建和 ESLint 通过。
- 42 个接口、枚举、存储等相关文件保持原样，240 处设置内部取值和默认值保持原样。
- 浏览器检查覆盖首页、七个设置分区、模型管理及上下文筛选、API 密钥输入和验证。
- 隔离模拟模型验证发送与回复、英文文本及代码保持原样、系统消息添加与取消、分支对话弹窗。
- 检查桌面和 390px 窄屏、深浅主题，以及设置保存后刷新保留。
- 实测“启用中文 → 恢复原版 → 再启用中文”；恢复后的页面与原始官方页面逐字节一致。

**未下载模型或执行真实模型推理。** 模拟聊天流程验证不能代替真实模型的使用验收。详见 [验收记录](../验收记录.json)。

## 实现与许可

通过官方应用已有的 Custom web app 设置加载网页资源，不修改应用本体、签名或自动更新设置。

模型名称、聊天内容、代码、接口字段、存储标记和模型提示词保持原样；第三方返回的内容也保持原样。

第三方许可详见 [LICENSES](../LICENSES/) 和 [THIRD_PARTY_NOTICES.txt](../THIRD_PARTY_NOTICES.txt)。后者包含固定构建环境中的依赖及仅用于构建的工具，不代表所有包都在运行时使用。

适配、脚本和验收工作使用了 AI 辅助。反馈问题时请先移除 API 密钥、访问令牌、私人聊天和完整配置。
